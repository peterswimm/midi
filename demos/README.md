# Demos

Interactive, self-contained web toys built from this database's world of gear.

## Gritty Grids — a bytebeat drum machine

`gritty-grids.html` — a single self-contained HTML file (no build, no dependencies; open it in a browser).

A playable exploration of the question *"what if [Mutable Instruments Grids](https://github.com/sonic-insurgence/Gritty-Grids) is actually a bytebeat drum machine?"* It fuses two ideas:

- **Grids** — a topographic drum sequencer that stores 25 pattern "nodes" in a 5×5 map and bilinearly interpolates between the four nearest ones as you move an X/Y position.
- **Bytebeat** — music generated by a tiny arithmetic/bitwise expression of a time counter `t` (viznut's *"Collection of oneliner music formulas"*, 2011).

Here the 25 map nodes are 25 real, attributed bytebeat one-liners. Moving the X/Y puck bilinearly blends the four nearest programs into one groove, and everything downstream is derived from that blend:

- **Rhythm source** — *Roles* (a Four / Backbeat / Eighths skeleton) or *Formula* (threshold the interpolated curve, so the pattern itself comes from the program and morphs as you drag).
- **Polyrhythm** — in Formula mode each of the three tracks has its own length (default 16 / 12 / 9), so the groove-slices phase against each other.
- **Two engines** — *Bitseq* renders each hit as a short wavetable grain of the current interpolated formula (so the drum timbre morphs with the map); *Bit voice* makes each lane a sustained 1-bit bytebeat oscillator, the way you'd repurpose Grids' three trigger outs as three voices.
- **Per-voice A / R** (envelope / drum length), **P** (trigger probability that ratchets into exponential rolls past ¾), and a unified **Chaos** knob that mutates pattern, timing, and per-hit timbre.

Audio is synthesized with the Web Audio API; nothing is sampled or fetched. Theme-aware (light/dark).
